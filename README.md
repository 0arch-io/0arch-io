## 0ARCH

Low-level systems work in Rust, mostly emulators and an operating system written from scratch,
plus a few machine learning projects. Everything here is built and maintained by one person.

### Projects

- **[gameboy](https://github.com/0arch-io/gameboy)**: Game Boy and Game Boy Color emulator
  written from scratch in Rust, with sound. Pokémon Red runs start to finish.
- **[gba](https://github.com/0arch-io/gba)**: Game Boy Advance emulator in Rust. Pokémon FireRed
  is fully playable and frame-identical to mGBA.
- **Nintendo DS emulator**: in progress, dual-screen ARM9 and ARM7 core in Rust.
- **x86-64 operating system**: in progress, written from scratch in Rust, boots on UEFI.
- **[Kisoku-3.2b](https://huggingface.co/0arch-io/Kisoku-3.2b)**: an open, community-trained
  language model built on TPU, with the full training methodology, code, and data notes
  published. ([training code](https://github.com/0arch-io/Kisoku-3.2b))
- **[magi](https://github.com/0arch-io/magi)**: a three-agent decision CLI. Three local models
  argue, rebut each other by name, and land on consensus or deadlock. Nothing leaves the machine.
