## 0ARCH

I build custom CRMs, internal tools, client portals, and dashboards for businesses that have
outgrown spreadsheets. Fixed scope, and you own the code at the end.

Everything here is written by one person. That is the point: you talk to whoever is going to
build it.

### Selected work

- **CTI ERP** — orders, shipping, invoicing, and reporting for a telecom distributor. A
  100,000-row product import went from three days of manual entry to seconds.
  [Case study](https://0arch.io/work/cti-erp)
- **Client portals and internal tools** — approval flows, audit trails, role permissions, and
  the unglamorous data plumbing underneath. [More work](https://0arch.io/work)

### Open source

- **[magi](https://github.com/0arch-io/magi)** — a CLI decision council. Three local models
  argue, rebut each other by name, and land on consensus or deadlock. Runs on Ollama, nothing
  leaves the machine.
- **[Kisoku-3.2b](https://huggingface.co/0arch-io/Kisoku-3.2b)** — a language model trained
  from scratch on TPU clusters, with the full methodology published.

### Products

- **[Sayo](https://0arch.io/products/sayo)** — voice notes for iPhone and Apple Watch.
  Transcription and extraction both run on device, so a memo never has to leave the phone.
- **[0Daily](https://0arch.io/products/0daily)** — four daily puzzles, no ads, no tracking-driven
  monetization. Built because every free puzzle app is buried under interstitials.
