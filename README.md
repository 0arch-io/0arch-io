## 0ARCH

0ARCH builds custom websites, web apps and business systems: CRMs, client portals, internal
tools and automations for businesses that have outgrown spreadsheets. Every project is built
and maintained by one person you can text.

- Website and work: [0arch.io](https://0arch.io)
- Apps on the App Store: [0arch.io/products](https://0arch.io/products)
- Contact: contact@0arch.io

### Open source

- **[Kisoku-3.2b](https://huggingface.co/0arch-io/Kisoku-3.2b)**: an open, community-trained
  language model built on TPU, with the full training methodology, code, and data notes
  published. ([training code](https://github.com/0arch-io/Kisoku-3.2b))

Personal systems projects (Game Boy and GBA emulators in Rust, the
